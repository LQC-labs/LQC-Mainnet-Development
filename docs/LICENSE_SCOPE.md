# 메인넷 자체 소스와 별도 FLOW 프로젝트의 구분

LQC 메인넷 개발팀과 FLOW 개발팀은 별개입니다. 메인넷 자체 코드의 기존 선언 라이선스는 루트 LICENSE의 Apache-2.0이며, 명시된 기존 제1자 고지는 보존합니다. 공개 저장소 main의 기존 LICENSE와 해시가 같은 전문을 사용합니다. 이는 모든 제3자 코드의 소유권이나 배포 권한을 주장하지 않습니다. 의존성 라이선스는 각각 유지됩니다.

FLOW 원본 소스, 계약, 수정 사본, 컴파일 입력/출력, 바이트코드, 추출 ABI, 빌드 provenance는 공개 후보에서 제외합니다. FLOW의 라이선스·저작권 확인 문제는 별도 팀의 자료에 한정되며 메인넷 자체 소스의 업로드 차단 사유로 전이하지 않습니다. 기존 FLOW 라이선스나 저작권 정보는 수정하지 않습니다.

메인넷의 독자적인 FLOW 호환 어댑터·오프라인 테스트 코드는 남겨 둡니다. lqcd start/앱/Genesis의 코어 빌드에는 FLOW 계약 소스나 바이트코드가 필요하지 않습니다. internal/mvpsafety의 선택형 배포·관측 경로는 별도 FLOW 입력을 요구하므로 해당 기능과 테스트는 외부 자료 공급 시에만 검증됩니다. 세부 경로와 실행 방법은 FLOW_EXTERNAL_TESTS.md를 참조하세요.

본 후보의 범위는 메인넷 개발 1~4단계 보존본과 테스트 자료 분리 변경입니다. 5단계 소스/증거는 수정하거나 병합하지 않았습니다. 업로드 준비와 공개 메인넷 운영 준비는 별개이며, 운영용 키·배포·공개 네트워크 실행은 승인되지 않았습니다.
